فارسی‌ساز Deadlock

تجربه بازی به زبان فارسی. نصب آسان، امن و قابل بازگشت. مخصوص جامعه فارسی‌زبان.

دانلود و شروع نصب

اطلاعات کلیدی

  • ترجمهٔ منوها، آیتم‌ها و تنظیمات (در حال تکمیل)
  • پشتیبان‌گیری خودکار از فایل‌های استیم
  • قابل به‌روزرسانی؛ سازگاری با نسخه‌های بازی نیاز به بررسی دارد

پیش‌نیازها

برای نصب به Python 3 و Git نیاز دارید؛ در لینوکس curl و در ویندوز راه‌انداز py نیز لازم است. پیش از نصب یا به‌روزرسانی، بازی را کاملاً ببندید.

دریافت سورس کد

راهنمای نصب

دستور سیستم‌عامل خود را کپی و در ترمینال اجرا کنید.

OS DETECTED

Linux 🐧

Bash · Git · Python 3 · curl

set -o pipefail; curl -fsSL https://raw.githubusercontent.com/deadlockpersian/deadlock-persian/main/scripts/bootstrap.sh | bash -s -- install
OS DETECTED

Windows 🪟

PowerShell · Git for Windows · Python 3 (py)

& ([scriptblock]::Create((Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/deadlockpersian/deadlock-persian/main/scripts/bootstrap.ps1').Content)) -Action install

دکمهٔ به‌روزرسانی دستور جدید را نمایش می‌دهد؛ برای اعمال آن، دستور را در ترمینال اجرا کنید. اسکریپت از فایل‌های اصلی پشتیبان می‌گیرد و اگر فایل‌های نصب‌شده تغییر کرده باشند، به‌روزرسانی را متوقف می‌کند.

اگر بازی پیدا نشد، در لینوکس مسیر پوشهٔ citadel را در انتهای دستور داخل کوتیشن اضافه کنید؛ در ویندوز -GameDir "C:\path\to\Deadlock\game\citadel" را به انتهای دستور PowerShell اضافه کنید. جزئیات حذف و بازگردانی در README است.

این دستورها اسکریپت‌های شاخهٔ main مخزن اصلی را دریافت می‌کنند. پیش از اجرا، محتوای اسکریپت را بررسی کنید. اسکریپت‌های فعلی هنوز به مخزن قدیمی و شاخهٔ arena ارجاع داخلی دارند؛ تا اصلاح آن‌ها در پروژهٔ اصلی، ممکن است نصب یا به‌روزرسانی با خطا مواجه شود.
