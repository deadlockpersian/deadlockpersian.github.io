# Deadlock Persian website

سایت ایستای فارسی‌ساز Deadlock؛ فایل اصلی `index.html` است و تصاویر محلی در `assets` نگهداری می‌شوند.

## افزودن اسکرین‌شات

- تصاویر PNG را در `assets/Screenshots` با نام‌های `1.png`، `2.png`، `3.png` و … قرار دهید.
- شماره‌ها باید پیوسته و بدون فاصله باشند. گالری از ۱ شروع می‌کند و با اولین فایل ناموجود یا خراب متوقف می‌شود.
- برای تصویر بعدی، فقط فایل شمارهٔ بعد را بارگذاری و سایت را منتشر کنید؛ نیازی به تغییر `index.html` یا همگام‌سازی با مخزن فارسی‌ساز نیست.
- تصاویر جدید پس از بارگذاری مجدد صفحه شناسایی می‌شوند. گالری و نمایش تمام‌صفحه از همان فایل‌های محلی استفاده می‌کنند و به API گیت‌هاب وابسته نیستند.

## دستورهای نصب

دستورهای نصب و به‌روزرسانی لینوکس و ویندوز، اسکریپت‌های `scripts/bootstrap.sh` و `scripts/bootstrap.ps1` را از شاخهٔ `main` مخزن https://github.com/deadlockpersian/deadlock-persian دریافت می‌کنند.

نکته: در زمان بررسی، README و ارجاع‌های داخلی اسکریپت‌های پروژهٔ اصلی هنوز از `BDadmehr0` و شاخهٔ `arena/435414a8-deadlock-persian` استفاده می‌کنند. اصلاح این ارجاع‌های داخلی باید در همان پروژه انجام شود؛ تغییر لینک‌های این سایت به‌تنهایی آن مشکل را رفع نمی‌کند.
